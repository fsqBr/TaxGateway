# Registro de Decisões (TaxGateway)

Toda decisão técnica tomada durante a implementação fica registrada aqui, com o motivo e onde ela está aplicada.
O SDD (`SDD.md`) descreve o desenho e este arquivo registra o que foi decidido ao construir. Quando os dois divergirem,
vale a decisão mais recente daqui, e o SDD é corrigido na mesma entrega.

* **Numeração:** `D-0xx` para a Fase 0, `D-1xx` para a Fase 1, `D-2xx` para a Fase 2, `D-3xx` para a Fase 3 e assim por diante: cada fase usa a sua centena.
* **Status:** `ATIVA`, `SUBSTITUÍDA por D-xxx` ou `REVOGADA`.
